COALITION BUILDER

QUICK PREVIEW

The easiest way to test the app is to open CoalitionBuilderPreview.html.
Double click it and it should open in Chrome, Edge, Safari or Firefox.

The preview is a single self contained HTML file, so you do not need a server.

FULL WEBSITE PACKAGE

The full website is also included in this folder:

index.html
styles.css
app.js
manifest.json
service_worker.js
assets

For normal local testing, you can also double click index.html.

For offline caching and the closest test to the published website:

1. Open a terminal or Command Prompt in this folder.
2. Run:

python -m http.server 8000

3. Visit localhost:8000 in your browser.

GITHUB PAGES

1. Create a free GitHub account if you do not already have one.
2. Create a new public repository.
3. Upload every file and the assets folder from this package.
4. Open the repository Settings.
5. Open Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select the main branch and root folder.
8. Save.
9. GitHub will give you a public website address.

You can turn that address into a QR code for participants.

Other leaders currently use clean initials avatars. They can be replaced with photographs later.

HOW THE ACTIVITY WORKS

1. Participants choose parties and try to reach 61 seats.
2. Once they reach a majority, they check policy compatibility.
3. They decide whether the policy differences could be negotiated.
4. The app then reveals the Netanyahu coalition question.
5. The coalition is re evaluated according to each party's stance.

Each participant who opens the website runs their own independent copy of the game in their browser. No login or shared database is required.
