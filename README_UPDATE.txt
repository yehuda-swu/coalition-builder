61: BUILD THE COALITION
Coalition negotiations update | 25 November 2026

WHAT THIS UPDATE DOES
This is a MERGE UPDATE for the existing GitHub repository. Do not delete the existing files.
The current election results, original images, original gameplay and all three modes are retained.

1. Adds a coalition negotiations briefing to each active game mode.
2. Adds a dedicated unity government leadership challenge for Yashar and Likud.
3. Models Netanyahu led, Eisenkot led and rotation proposals separately.
4. The Eisenkot led outcome is deliberately marked as hypothetical, not a confirmed agreement.
5. Reflects the reported Yashar and Yisrael Beytenu coalition agreement.
6. Reflects the Democrats suspending talks over a unity government.
7. Opens the Yisrael Beytenu and Charedi negotiations as a conditional policy negotiation.
8. Retains the Joint Arab List formal coalition restriction and other existing vetoes.
9. Keeps current final seat allocations, minority government route and coalition strength logic.
10. Refreshes browser caching for this release.
